## Как запустить

1. Сборка Docker образа
```bash
docker build -t my-web-app:latest .
```

2. Запуск Docker
```bash
docker run -d -p 8080:80 my-web-app:latest
```

3. Вариант запуска через Docker compose
```bash
docker run -d -p 8080:80 my-web-app:latest
```

4. Проверка работы - открой брайузер с адресом:
http://localhost:8080
